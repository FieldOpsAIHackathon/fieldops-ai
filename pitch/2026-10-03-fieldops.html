The language model never computes the date. Timing is auditable code, so the same season always gives the same answer.

Three steps, all on the GB10. A YOLO detector counts the pests in a trap photo. Plain Python finds biofix, adds up degree-days and opens the window. The language model only phrases the alert and answers questions. It never computes the date, because a hallucinated spray date costs someone a harvest.

Every model runs on the Dell GB10: YOLO for counting, Qwen for the agent, Kokoro for speech. The Telegram agent is OpenClaw inside a NemoClaw sandbox, behind OpenShell, and a network policy lets it reach only our tool API. Telegram carries the photo in and the alert out. Inference never leaves the box.
